Claude Code local: thiết lập môi trường offline cho lập trình bằng AI

Thiết lập môi trường lập trình AI chạy cục bộ với Claude Code và Ollama: chuẩn bị, nâng ngữ cảnh, kiểm tra từng bước và hiểu đúng chữ offline.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-20 · 7 phút đọc

Trả lời nhanh: Để làm việc gần như offline, bạn cài sẵn Claude Code và Ollama, tải một mô hình hỗ trợ gọi công cụ với ngữ cảnh từ 64.000 token trở lên, rồi trỏ Claude Code tới Ollama trên máy. Phần cài đặt và tải mô hình vẫn cần internet; chỉ sau đó mới chạy được không cần mạng, và một số tính năng như tìm kiếm web sẽ không dùng được.

"Offline" thật ra là gì

Đây là chỗ dễ hiểu nhầm. Chạy cục bộ nghĩa là mô hình suy luận trên máy bạn nên nội dung code không đi ra ngoài để xử lý. Nhưng:

  • Bạn vẫn cần internet khi cài đặt công cụ và tải mô hình.
  • Các tính năng cần mạng, như tìm kiếm web, sẽ không hoạt động.
  • Bạn nên tự kiểm tra xem các công cụ có thực hiện kết nối mạng nền nào khác không (cập nhật, đo lường), vì phần này tùy phiên bản và cấu hình.

Nếu yêu cầu của bạn là tuyệt đối không có kết nối ra ngoài, hãy kiểm chứng bằng cách theo dõi lưu lượng mạng thay vì tin vào tên gọi.

Bước 1: Chuẩn bị phần cứng

Mô hình càng lớn càng cần nhiều bộ nhớ. Hướng dẫn chạy agent cục bộ của Nous Research đưa ra mức tham khảo: khoảng 8 GB RAM cho mô hình cỡ 3 tỷ tham số và từ 32 GB trở lên cho mô hình từ 27 tỷ tham số, còn card đồ họa NVIDIA có từ 8 GB bộ nhớ riêng giúp nhanh hơn đáng kể. Hãy đối chiếu dung lượng ghi trên trang từng mô hình trong thư viện Ollama.

Bước 2: Cài các thành phần (lúc còn mạng)

  1. Cài Claude Code, xem Thiết lập Claude Code từng bước.
  2. Cài Ollama từ ollama.com và kiểm tra:
ollama --version
  1. Tải mô hình bạn chọn:
ollama pull ten-mo-hinh

Chọn mô hình hỗ trợ gọi công cụ, vì Claude Code làm việc bằng công cụ. Tài liệu của Ollama khuyên đặt ngữ cảnh từ 64.000 token trở lên cho mô hình cục bộ.

Bước 3: Nâng độ dài ngữ cảnh

Theo tài liệu hiện hành của Ollama, ngữ cảnh mặc định phụ thuộc bộ nhớ card đồ họa (VRAM): dưới 24 GiB là 4k, từ 24 đến 48 GiB là 32k, từ 48 GiB trở lên là 256k; việc dùng agent và công cụ lập trình nên đặt ít nhất 64.000. Hướng dẫn của Hermes Agent vẫn ghi mặc định 2048 token, không khớp với trang này. Bạn có thể đặt biến OLLAMA_CONTEXT_LENGTH=64000 khi chạy ollama serve, hoặc tạo phiên bản mô hình có ngữ cảnh lớn hơn bằng Modelfile:

cat > Modelfile << 'EOF'
FROM ten-mo-hinh
PARAMETER num_ctx 64000
EOF
ollama create ten-mo-hinh-64k -f Modelfile

Kiểm tra ngữ cảnh đang được cấp bằng ollama ps (cột CONTEXT). Ngữ cảnh càng dài càng tốn bộ nhớ, nên chọn mức vừa đủ.

Bước 4: Trỏ Claude Code tới Ollama

Cách nhanh theo tài liệu của Ollama:

ollama launch claude

Hoặc đặt biến môi trường thủ công:

export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_API_KEY=""
export ANTHROPIC_BASE_URL=http://localhost:11434
claude --model ten-mo-hinh-64k

Sau khi chạy, dùng /status trong Claude Code để chắc chắn nó đang kết nối đúng nơi. Tài liệu lưu ý các file cấu hình của Claude có thể ghi đè biến môi trường.

Bước 5: Kiểm tra theo thứ tự

  1. Ngắt mạng (hoặc bật chế độ máy bay) rồi hỏi một câu đơn giản. Nếu trả lời được, đường truyền cục bộ hoạt động.
  2. Giao một tác vụ chỉ đọc: "Giải thích cấu trúc thư mục này, không sửa file."
  3. Giao một sửa đổi nhỏ trong chế độ chỉ lập kế hoạch rồi duyệt.
  4. Chạy lại bộ lệnh kiểm thử của dự án để chắc thay đổi không phá hỏng gì.

Giữ mô hình sẵn sàng

Ollama có thể gỡ mô hình khỏi bộ nhớ sau một thời gian không dùng, khiến lần hỏi tiếp theo chậm. Hướng dẫn của Hermes mô tả cách giữ mô hình nạp lâu hơn bằng tham số keep_alive hoặc biến OLLAMA_KEEP_ALIVE. Dùng ollama ps để xem mô hình nào đang nạp.

Những gì bạn sẽ không có

  • Tìm kiếm web và các tính năng cần dịch vụ trực tuyến.
  • Chất lượng ngang các mô hình hàng đầu. Mô hình cục bộ nhỏ thường yếu hơn ở việc nhiều bước và code lớn.
  • Tốc độ như dịch vụ đám mây, nhất là khi chỉ có CPU.

Bảo mật và an toàn

Chạy cục bộ không làm agent an toàn hơn trong chuyện sửa file. Hãy giữ nguyên các thói quen: dự án nằm trong Git, bắt đầu ở chế độ chỉ lập kế hoạch, chặn đọc các file bí mật bằng quy tắc từ chối, và không dùng cờ bỏ qua toàn bộ quyền ngoài môi trường cô lập.
