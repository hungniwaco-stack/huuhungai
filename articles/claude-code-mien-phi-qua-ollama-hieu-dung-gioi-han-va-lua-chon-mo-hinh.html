Claude Code miễn phí qua Ollama: hiểu đúng giới hạn và lựa chọn mô hình

Cách chạy Claude Code với mô hình khác qua Ollama theo tài liệu chính thức: lệnh khởi chạy, biến môi trường, chọn mô hình, và những giới hạn cần hiểu đúng.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-20 · 7 phút đọc

Trả lời nhanh: Claude Code có thể dùng mô hình chạy qua Ollama thay vì mô hình của Anthropic. Cách nhanh nhất là lệnh ollama launch claude. Nó không tốn phí theo lượt khi chạy cục bộ, nhưng bạn đổi lấy chất lượng, khả năng gọi công cụ và một số tính năng có thể kém hơn, nên "miễn phí" cần được hiểu đúng.

Nó hoạt động thế nào

Ollama hỗ trợ giao diện tương thích với Anthropic Messages API. Nhờ đó Claude Code, vốn gọi API của Anthropic, có thể được trỏ sang một máy chủ khác bằng biến môi trường. Phần mềm bạn dùng vẫn là Claude Code, nhưng "bộ não" đứng sau là mô hình bạn chọn trong Ollama. Đây là cách chính thức được Ollama ghi trong tài liệu.

Cài đặt Claude Code và Ollama

Cài Claude Code theo hướng dẫn trong bài Thiết lập Claude Code từng bước, và cài Ollama từ ollama.com. Tài liệu của Ollama cho biết lệnh cài đặt Claude Code là:

# macOS, Linux
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

Cách 1: Khởi chạy nhanh

Khi đã có Ollama, một lệnh duy nhất khởi động Claude Code với Ollama:

ollama launch claude

Lệnh sẽ hướng dẫn bạn chọn mô hình. Tài liệu cũng nêu cách dùng không tương tác cho script, với cờ --model và --yes, trong đó --yes bắt buộc đi kèm --model.

Cách 2: Cấu hình thủ công cho mô hình chạy trên máy

Đặt ba biến môi trường rồi chạy Claude Code với tên mô hình:

export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_API_KEY=""
export ANTHROPIC_BASE_URL=http://localhost:11434
claude --model ten-mo-hinh

Biến ANTHROPIC_AUTH_TOKEN chỉ cần có giá trị, Ollama không kiểm tra nó. Trên Windows PowerShell, dùng $env:TÊN = "giá trị" thay cho export.

Cách 3: Dùng mô hình đám mây của Ollama

Bạn cũng có thể dùng các mô hình đám mây (tên có hậu tố :cloud) qua Ollama mà không cần tải về máy. Tài liệu còn mô tả cách kết nối thẳng tới https://ollama.com bằng khóa API của Ollama, đặt trong biến ANTHROPIC_AUTH_TOKEN. Với cách này, mô hình không chạy trên máy bạn, nên điều kiện sử dụng, giới hạn và chi phí do dịch vụ quy định. Hãy xem trang giá của Ollama trước khi dựa vào nó.

Chọn mô hình: hai điều kiện bắt buộc

Tài liệu Ollama nêu hai yêu cầu cho mô hình chạy cục bộ:

  • Hỗ trợ gọi công cụ. Claude Code hoạt động bằng cách gọi công cụ (đọc file, sửa file, chạy lệnh). Mô hình không hỗ trợ điều này sẽ chỉ trò chuyện được.
  • Cửa sổ ngữ cảnh từ 64.000 token trở lên. Dự án lớn cần ngữ cảnh lớn để agent đọc đủ code.

Với dự án lớn, hãy đặt độ dài ngữ cảnh từ 64.000 trở lên. Máy yếu khó đáp ứng cả hai điều kiện cùng lúc, đó là lý do nhiều người thấy kết quả chậm hoặc kém.

"Miễn phí" nghĩa là gì và không nghĩa là gì

  • Đúng: chạy mô hình cục bộ không tính phí theo số token, và nội dung không phải gửi tới dịch vụ bên ngoài để xử lý.
  • Không hẳn: bạn dùng điện, phần cứng và thời gian. Mô hình lớn cần máy mạnh.
  • Mô hình đám mây: có thể có giới hạn hoặc phí, tùy gói của Ollama.
  • Chất lượng khác biệt: mô hình nhỏ chạy trên máy cá nhân thường kém hơn các mô hình hàng đầu ở việc lập trình phức tạp, và kết quả sẽ khác với khi dùng Claude.

Giới hạn và lưu ý theo tài liệu Ollama

  • Tìm kiếm web do dịch vụ lưu trữ cung cấp và một số điều khiển công cụ nâng cao không được hỗ trợ đầy đủ khi kết nối thẳng tới đám mây. Trò chuyện cơ bản và chỉnh sửa file hoạt động với mô hình tương thích.
  • Thiết lập của Claude có thể ghi đè biến môi trường. Nếu bạn đổi địa chỉ hoặc thông tin xác thực, hãy cập nhật cả trong các file cấu hình của Claude, rồi chạy /status để kiểm tra kết nối.
  • Claude Code vẫn hỏi quyền với hầu hết thao tác. Chế độ tự chạy hoàn toàn cần luật cho phép hoặc cờ bỏ qua quyền, và cờ đó chỉ nên dùng trong môi trường cô lập.

Khi nào đáng dùng cách này

  • Bạn muốn thử Claude Code mà không cấu hình thuê bao, hoặc làm việc với mã nguồn không thể gửi ra ngoài.
  • Việc cần làm đơn giản và rõ ràng, như sửa nhỏ, giải thích code, viết kiểm thử.
  • Bạn chấp nhận chậm hơn và phải kiểm tra kỹ hơn.

Nếu cần chất lượng cao nhất cho việc phức tạp, hãy dùng mô hình của Anthropic. Muốn dựng môi trường làm việc hoàn toàn không phụ thuộc mạng, xem Claude Code local: thiết lập môi trường offline.
