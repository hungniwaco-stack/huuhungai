Open Design và Claude Design cho agency: chọn công cụ thiết kế AI thế nào?

Open Design là không gian thiết kế mã nguồn mở dùng agent có sẵn trên máy: cài đặt, xuất bản, riêng tư và cách chọn so với dịch vụ thiết kế AI đám mây cho agency.

Tác giả: Hữu Hùng · Xuất bản: 2026-05-08 · 7 phút đọc

Trả lời nhanh: Open Design (kho nexu-io/open-design, giấy phép Apache-2.0) là không gian thiết kế cho agent AI, ưu tiên chạy cục bộ và dùng các CLI agent bạn đã cài thay vì tự đóng gói mô hình. Tôi không có dữ liệu so sánh chất lượng với Claude Design, nên bài so sánh theo tiêu chí chọn công cụ: nơi chạy, dữ liệu, chi phí mô hình, định dạng xuất và mức trưởng thành.

Open Design là gì

Theo README, Open Design là không gian thiết kế cho agent AI: bạn bắt đầu bằng một brief, dùng một coding agent hoặc OpenDesign Cloud để dựng nguyên mẫu theo hệ thống thiết kế của bạn, đồng đội xem lại và agent tinh chỉnh trong cùng dự án. Có kỹ năng, mẫu thiết kế, hệ thống thiết kế và plugin mà người dùng xem và chỉnh được. Giấy phép Apache-2.0, một số kỹ năng và mẫu gói kèm giữ giấy phép riêng (như MIT).

Nhiều kho trên GitHub là bản fork mang cùng mô tả; kho gốc theo kết quả tìm kiếm là nexu-io/open-design. Số sao và số kỹ năng trong các bài giới thiệu không khớp nhau, hãy xem kho gốc.

Cài đặt và nền tảng

  • Ứng dụng Desktop: macOS (Apple Silicon và Intel) và Windows (x64), tải từ open-design.ai hoặc GitHub Releases. Linux chưa có bản dựng sẵn, README nói tạm chạy từ mã nguồn.
  • Cài vào agent bạn đang dùng:
od mcp install <agent>

Với <agent> là một trong các agent được README liệt kê (như claude, codex, cursor, copilot, openclaw, hermes, kimi, opencode...). Có lệnh tương đương qua curl ... | sh từ open-design.ai; nên đọc tập lệnh trước khi chạy.

  • Docker:
git clone https://github.com/nexu-io/open-design.git
cd open-design/deploy
cp .env.example .env
echo "OD_API_TOKEN=$(openssl rand -hex 32)" >> .env
docker compose up -d

rồi mở http://127.0.0.1:7456.

  • Từ mã nguồn: cần Node ~24 và pnpm 10.33.x.

Cách nó dùng agent

Ứng dụng Desktop tự dò các CLI agent trên PATH; README nói hỗ trợ khoảng 26 CLI. Khi chạy với agent có quyền tệp, agent kết hợp kỹ năng hoặc mẫu đã chọn với tệp DESIGN.md của bạn, ghi tệp dự án và Open Design xem trước. Với chế độ tự mang khóa (BYOK) không có công cụ tệp, agent trả về một khối <artifact> hoàn chỉnh. BYOK hỗ trợ OpenAI, Anthropic, Azure OpenAI, Gemini, Ollama, LM Studio, vLLM và mọi endpoint tương thích OpenAI. Cũng có "OpenDesign Cloud", dịch vụ mô hình chính thức tích hợp trong ứng dụng.

Đầu ra và bàn giao

Nguyên mẫu dạng trang HTML hiển thị trong iframe hộp cát; bộ trình chiếu xuất ra HTML, PDF, PPTX, ZIP hoặc Markdown; ảnh qua gpt-image-2, ImageRouter hoặc API tùy chỉnh; video chuyển động (HyperFrames) xuất MP4. README nói HTML và CSS có thể đưa tiếp vào Cursor, Codex hay Claude Code.

Riêng tư và bảo mật

  • README gọi sản phẩm là "local-first": dự án chạy cục bộ hoặc trong hệ thống bạn tự triển khai. Yêu cầu tới mô hình đám mây và OpenDesign Cloud được gửi tới dịch vụ tương ứng.
  • Phân tích sản phẩm và ghi lại phiên chỉ khi bạn đồng ý; dữ liệu đo an toàn và độ tin cậy đã lọc luôn bật.
  • Tiến trình nền mặc định chỉ nghe 127.0.0.1; có chặn SSRF với dải địa chỉ nội bộ trừ khi bạn mở bằng OD_ALLOWED_INTERNAL_HOSTS.

Giới hạn README tự nêu

Chưa có bản Linux dựng sẵn; cấu hình MCP tự động cho Claude Desktop chỉ có trên macOS và Windows; chỉnh sửa tinh qua chế độ bình luận mới "một phần"; bảng chỉnh do AI đề xuất "chưa thực hiện"; còn trong kế hoạch: SDK plugin, chuyển từ Figma và Pencil sang mã. Trên macOS, lệnh /usr/bin/od có thể che lệnh od của Open Design.

Về Claude Design

Tôi không đọc được tài liệu chính thức của Claude Design nên không mô tả tính năng hay giá của nó; một số bài báo nói đó là dịch vụ đám mây gắn với một mô hình của Anthropic, nhưng đó là thứ cấp. Hãy đọc trang chính thức của Anthropic trước khi so sánh.

Cách chọn cho agency

  1. Nơi dữ liệu nằm: khách hàng có cho phép tài sản thiết kế rời máy không? Cục bộ có lợi.
  2. Chi phí mô hình: Open Design dùng agent và khóa bạn đã có; dịch vụ đám mây tính theo gói. Tính theo khối lượng thực tế.
  3. Định dạng xuất: có đáp ứng nhu cầu bàn giao (HTML, PDF, PPTX)?
  4. Mức trưởng thành: README còn nhiều mục "chưa xong"; thử trên một dự án nhỏ.
  5. Kiểm soát quyền agent: agent ghi tệp thật; chạy trong thư mục riêng và duyệt thay đổi, xem bài học bảo mật.
