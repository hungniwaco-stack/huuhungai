Mission Control cho OpenClaw: dashboard cộng đồng và Control UI chính thức

Mission Control cho OpenClaw không phải sản phẩm chính thức: so sánh Control UI chính thức với các dashboard cộng đồng và cách mở Control UI an toàn từ xa.

Tác giả: Hữu Hùng · Xuất bản: 2026-05-05 · 7 phút đọc

Trả lời nhanh: OpenClaw đã có bảng điều khiển chính thức là Control UI, mở bằng openclaw dashboard. Các dự án "Mission Control" là sản phẩm cộng đồng độc lập, thêm bảng Kanban và theo dõi agent. Dù dùng cái nào, giữ Gateway ở loopback và truy cập từ xa qua Tailscale Serve hoặc mạng riêng, không mở thẳng ra Internet. Nếu chỉ cần bảng việc kiểu Kanban, OpenClaw còn có plugin chính thức Workboard, mặc định tắt.

Control UI chính thức

Control UI là bảng điều khiển trên trình duyệt cho Gateway OpenClaw đang chạy. Mở bằng:

openclaw dashboard

Lệnh tạo một liên kết ghép cặp dùng một lần, hết hạn sau mười phút. Khi ghép cặp thành công, trình duyệt đó nhận một thông tin xác thực quản trị theo thiết bị, nên lần sau mở lại không cần token chung của Gateway. Token chung không được in ra terminal. Thêm --no-open để chỉ in địa chỉ, --json để in một đối tượng kết nối cho máy đọc. Tài liệu còn mô tả cấu hình nhà cung cấp, xoay khóa API và chỉnh sửa máy chủ MCP ngay trong giao diện này. Cài đặt lần đầu xem Cài OpenClaw.

Các "Mission Control" cộng đồng

Tìm trên GitHub thấy nhiều kho độc lập dùng tên này cho OpenClaw, không có một bản duy nhất chính thức. Theo mô tả công khai của từng kho:

  • Một số có bảng Kanban giao việc cho agent, theo dõi trạng thái agent, nhật ký hoạt động trực tiếp, các tác vụ định kỳ.
  • Một số chỉ là bảng theo dõi chỉ đọc, một số là trung tâm điều khiển rộng hơn dùng cả với Claude Code và Codex.
  • Có kho đã bị chủ sở hữu lưu trữ (archived), chỉ đọc, nên không nên dùng cho thiết lập mới.

Một ví dụ cụ thể là navjotdhanawat/openclaw-mission-control. README mô tả đây là dashboard thời gian thực có bảng Kanban năm cột (Inbox, Assigned, In Progress, Review, Done), giám sát agent và giao việc trực tiếp. Chạy bằng npx openclaw-mission-control rồi nhập địa chỉ Gateway (mặc định ws://127.0.0.1:18789), token xác thực và cổng (mặc định 3000). Cần Node 18 trở lên và một Gateway đang chạy. Khi kiểm tra ngày 28/11/2026, lần cập nhật mã gần nhất của kho là ngày 21/2/2026, tức hơn chín tháng trước, nên hãy kiểm tra kỹ độ tương thích với bản OpenClaw bạn đang chạy.

Cảnh báo bảo mật với dashboard cộng đồng

README của kho vừa nêu chỉ yêu cầu token của Gateway và không hướng dẫn bảo vệ chính dashboard (không nói về kiểm soát truy cập giao diện web hay API REST của nó), và địa chỉ mặc định dùng ws:// thay vì wss://. Nghĩa là nếu mở dashboard ra mạng, ai vào được là điều khiển được agent. Hãy:

  • Chỉ chạy ở máy của bạn (localhost) hoặc sau mạng riêng.
  • Đọc mã nguồn hoặc ít nhất xem kho đó còn hoạt động không trước khi đưa token Gateway vào.
  • Xem token Gateway như mật khẩu quản trị.

Truy cập Control UI từ xa an toàn

Tài liệu về Tailscale phân biệt hai chế độ:

  • Serve (gateway.tailscale.mode: "serve"): HTTPS chỉ trong mạng Tailscale của bạn, Gateway vẫn ở loopback. Lệnh: openclaw gateway --tailscale serve.
  • Funnel (gateway.tailscale.mode: "funnel"): HTTPS công khai ra Internet. Tài liệu nói bắt buộc có mật khẩu chung, và Gateway từ chối khởi động nếu chế độ xác thực không phải password. Tài liệu còn khuyên tránh Funnel cho việc điều khiển trình duyệt.

Một chi tiết cần lưu ý: gắn Gateway trực tiếp vào địa chỉ IP Tailnet làm lộ WebSocket qua HTTP thường, không mã hóa, nên tài liệu khuyên dùng Serve để có HTTPS. Ngoài ra có tùy chọn Cloudflare Tunnel và Access cho người muốn công bố qua Cloudflare. Chạy openclaw security audit để kiểm tra cấu hình, nguyên tắc chung xem Cài OpenClaw.

Khi nào cần một Mission Control

Nếu bạn chạy vài agent và chỉ cần xem trạng thái, Control UI là đủ. Nếu cần bảng việc kiểu Kanban, hãy thử plugin chính thức Workboard trước (openclaw plugins enable workboard). Chỉ cân nhắc bản cộng đồng khi nó có thứ bạn cần mà bản chính thức chưa có, và bạn chấp nhận tự kiểm tra rủi ro. Một cách nhìn chi tiết hơn về nhóm tính năng này nằm ở bài Mission Control: squad agent, task board và memory browser.
