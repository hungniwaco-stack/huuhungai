Thiết lập Claude Code từng bước: nền tảng cho coding bằng AI

Hướng dẫn cài Claude Code, đăng nhập, tạo CLAUDE.md, chọn chế độ quyền và giao tác vụ đầu tiên an toàn trên một dự án thật, từng bước một.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-29 · 7 phút đọc

Trả lời nhanh: Cài Claude Code bằng một lệnh, đăng nhập, mở terminal trong thư mục dự án, chạy /init để tạo file CLAUDE.md, rồi giao một tác vụ nhỏ ở chế độ chỉ lập kế hoạch. Cài đặt rất gọn; phần cần cẩn thận là quyền truy cập và cách giao việc.

Claude Code là gì và ai nên dùng

Claude Code là một trợ lý lập trình chạy ngay trong terminal. Khác với chatbot chỉ trả lời trong khung chat, nó đọc được dự án của bạn, sửa file, chạy lệnh và kiểm tra kết quả, nhưng mỗi hành động quan trọng đều cần bạn cho phép. Nó hợp với người làm website, tự động hóa hoặc công cụ nội bộ muốn giao việc lặp lại cho AI mà vẫn giữ quyền kiểm soát. Bạn không cần viết code giỏi, nhưng cần đọc được thay đổi mà nó đề xuất, hoặc có người xem lại trước khi đưa lên môi trường thật.

Chuẩn bị trước khi cài

  • Tài khoản: một gói Claude trả phí, hoặc một API key từ Anthropic Console. Chi phí và giới hạn thay đổi theo thời gian nên hãy xem trang giá chính thức thay vì tin con số cũ.
  • Git: bắt buộc nên có. Dự án nằm trong một kho Git giúp bạn xem lại và hoàn tác mọi thay đổi chỉ bằng một lệnh. Trên Windows, hãy cài Git for Windows hoặc dùng WSL.
  • Một dự án nhỏ để thử: đừng bắt đầu bằng dự án khách hàng đang chạy thật.

Bước 1: Cài đặt

Chọn một trong các cách dưới đây. Luôn lấy lệnh từ tài liệu chính thức của Anthropic, vì lệnh cài đặt có thể thay đổi theo phiên bản.

# macOS, Linux hoặc WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

# Hoặc qua npm (cần Node.js 18 trở lên)
npm install -g @anthropic-ai/claude-code

Mở một cửa sổ terminal mới rồi kiểm tra:

claude --version
claude doctor

Lệnh đầu in ra số phiên bản, lệnh thứ hai chẩn đoán các lỗi cài đặt thường gặp. Chỉ chạy script cài đặt từ đúng tên miền chính thức, không chạy script từ nguồn bạn không kiểm chứng được.

Bước 2: Mở trong dự án và đăng nhập

cd duong-dan/den/du-an-cua-ban
claude

Lần chạy đầu tiên, Claude Code mở trình duyệt để bạn đăng nhập bằng tài khoản Claude, hoặc cho bạn chọn dùng API key. Hãy luôn chạy lệnh claude trong thư mục dự án, không chạy ở thư mục gốc của ổ đĩa hay thư mục người dùng, vì khi đó nó có thể quét vào những file không liên quan.

Bước 3: Tạo CLAUDE.md để nó hiểu dự án

Gõ /init. Claude Code đọc dự án và tạo file CLAUDE.md ở thư mục gốc, nơi ghi những điều nó cần nhớ mỗi lần bắt đầu phiên làm việc. Đây là file đáng bỏ thời gian chỉnh nhất. Một bản gọn và hữu ích thường có:

# Dự án: website bán hàng nhỏ
- Chạy thử: npm run dev (cổng 3000)
- Kiểm tra: npm test
- Mã nguồn chính nằm trong thư mục src/
- Không sửa thư mục dist/ và file .env
- Văn phong giao diện: tiếng Việt, ngắn gọn

Đây chỉ là ví dụ minh họa, hãy thay bằng thông tin thật của dự án bạn. Viết ngắn, cụ thể và cập nhật khi quy ước thay đổi.

Bước 4: Hiểu chế độ quyền trước khi giao việc

Đây là phần quyết định bạn dùng Claude Code an toàn đến đâu. Mặc định, nó hỏi bạn trước khi sửa file hay chạy lệnh. Trong phiên làm việc, bạn có thể nhấn Shift+Tab để chuyển giữa các chế độ, trong đó có chế độ tự chấp nhận các chỉnh sửa file và chế độ plan (chỉ phân tích và đề xuất kế hoạch, không sửa gì). Khi mới làm quen, hãy ưu tiên chế độ mặc định hoặc plan, và tránh các chế độ bỏ qua toàn bộ xác nhận.

Để chặn nó đọc những file nhạy cảm, tạo file .claude/settings.json trong dự án:

{
  "permissions": {
    "deny": ["Read(./.env)", "Read(./secrets/**)"]
  }
}

Nội dung các file Claude Code đọc được sẽ được gửi đi để mô hình xử lý, nên đừng để khóa API, mật khẩu hay dữ liệu khách hàng trong phạm vi nó có thể đọc.

Bước 5: Giao tác vụ đầu tiên

Bắt đầu bằng việc không có rủi ro, rồi mới đến việc có sửa file:

  1. Đọc hiểu: “Đọc dự án và giải thích cấu trúc thư mục. Không sửa file nào.”
  2. Lập kế hoạch: bật chế độ plan và yêu cầu “Đề xuất kế hoạch thêm nút liên hệ vào trang chủ, liệt kê file sẽ sửa, chờ tôi duyệt.”
  3. Thực hiện và kiểm tra: duyệt kế hoạch, để nó làm, rồi tự xem lại bằng git diff trước khi giữ thay đổi.

Mỗi lần giao một việc rõ ràng. Dùng /clear khi chuyển sang việc khác để cuộc trò chuyện không bị lẫn, và /compact khi phiên làm việc đã quá dài. Hãy tự quyết định lúc nào commit, đừng để thay đổi chưa xem tích lũy.

Lỗi thường gặp

  • claude: command not found: mở terminal mới sau khi cài. Nếu vẫn lỗi, kiểm tra thư mục chứa lệnh đã nằm trong biến PATH chưa, hoặc chạy claude doctor.
  • Đăng nhập không được: kiểm tra bạn dùng đúng loại tài khoản (gói Claude hay API key) và đăng nhập lại.
  • Nó đọc quá nhiều file không liên quan: thường do chạy ở sai thư mục, hãy thoát và chạy lại trong thư mục dự án.
  • Kết quả không như ý: mô tả cụ thể hơn, đưa vào ví dụ, và chia nhỏ việc thay vì giao một yêu cầu quá lớn.

Checklist sau khi cài xong

  • Chạy được claude --version và đăng nhập thành công.
  • Dự án nằm trong Git và đã commit trạng thái hiện tại.
  • Có file CLAUDE.md ngắn gọn, đúng với dự án.
  • Đã chặn đọc các file nhạy cảm bằng permissions.deny.
  • Đã thử một tác vụ chỉ đọc và một tác vụ ở chế độ plan trước khi cho sửa file.
