Thiết lập Hermes Workspace: nền làm việc cho AI Agent

Cài Hermes Workspace, giao diện web cộng đồng cho Hermes Agent: yêu cầu, bốn cách cài, biến môi trường, cổng, bảo mật khi truy cập từ xa và cách kiểm tra.

Tác giả: Hữu Hùng · Xuất bản: 2026-05-05 · 8 phút đọc

Trả lời nhanh: Hermes Workspace (kho outsourc-e/hermes-workspace, giấy phép MIT) là giao diện web cộng đồng đứng trước Hermes Agent. Nó cần Node.js 22, pnpm và một gateway Hermes đang chạy ở cổng 8642. Chạy cục bộ thì đơn giản; mở ra ngoài mạng thì bắt buộc phải đặt mật khẩu.

Workspace là gì và không là gì

Hermes Workspace là ứng dụng web do cộng đồng viết (phiên bản 2.3.0 khi tôi đọc), không phải sản phẩm của Nous Research. README mô tả nó là giao diện còn Hermes Agent là bộ não, hai bên nói chuyện qua HTTP. Tính năng chính: chat dạng dòng chảy với hiển thị công cụ, quản lý bộ nhớ, duyệt kỹ năng, trang MCP, trình duyệt tệp với trình soạn Monaco, terminal, bảng điều hành nhiều agent, chế độ Conductor và Swarm, chủ đề giao diện, và cài như ứng dụng web tiến bộ (PWA). Nó cũng có "chế độ di động" (portable) chạy với mọi máy chủ tương thích OpenAI, khi đó chỉ chat dùng được.

Yêu cầu

  • Node.js 22 trở lên và pnpm.
  • Một gateway Hermes Agent hoặc máy chủ tương thích OpenAI. Không ghim phiên bản Hermes cụ thể; README khuyên dùng bản mới nhất.
  • Python 3.11 trở lên nếu muốn chạy gateway Hermes cục bộ.
  • Docker và Docker Compose nếu dùng cách Docker.

Các cổng

  • 3000: giao diện Workspace (đổi bằng biến PORT).
  • 8642: gateway Hermes (chat, mô hình, tác vụ).
  • 9119: bảng điều khiển Hermes (phiên, kỹ năng, cấu hình, MCP).

Bật máy chủ API phía Hermes

Phía gateway cần bật API_SERVER_ENABLED=true (bắt buộc). Nếu muốn truy cập từ máy khác thì thêm API_SERVER_HOST=0.0.0.0 cùng API_SERVER_KEY để xác thực. README nói gateway từ chối khởi động nếu mở 0.0.0.0 mà không có khóa. Cách này cũng là cách Hermes Open WebUI kết nối.

Cách 1: cài một dòng (macOS, Linux)

curl -fsSL https://raw.githubusercontent.com/outsourc-e/hermes-workspace/main/install.sh | bash
hermes gateway run
cd ~/hermes-workspace && pnpm dev

Hai lệnh sau chạy ở hai terminal khác nhau. Trước khi chạy tập lệnh tải về, hãy mở và đọc nó.

Cách 2: gắn vào Hermes đã cài

git clone https://github.com/outsourc-e/hermes-workspace.git
cd hermes-workspace
pnpm install
cp .env.example .env
echo 'HERMES_API_URL=http://127.0.0.1:8642' >> .env
echo 'HERMES_DASHBOARD_URL=http://127.0.0.1:9119' >> .env
pnpm dev

Cách 3: Docker Compose

cp .env.example .env
docker compose up

Cũng có ảnh dựng sẵn ghcr.io/outsourc-e/hermes-workspace:latest (cổng 3000) cho các nền tảng như Coolify, Easypanel, Dokploy, Unraid.

Cách 4: Windows

README có tập lệnh PowerShell chạy qua WSL: .\scripts\start-hermes-workspace.ps1 (thêm -Restart để khởi động lại). Dự án còn có hướng dẫn riêng cho Windows trong thư mục docs.

Biến môi trường chính

  • HERMES_API_URL: địa chỉ gateway, mặc định http://127.0.0.1:8642.
  • HERMES_DASHBOARD_URL: địa chỉ bảng điều khiển, mặc định http://127.0.0.1:9119.
  • HERMES_API_TOKEN: token cho gateway, phải khớp API_SERVER_KEY bên Hermes.
  • HERMES_PASSWORD: mật khẩu giao diện; bắt buộc khi không nghe ở 127.0.0.1.

Có thể đặt địa chỉ lúc chạy ở Settings, Connection.

Kiểm tra

curl http://127.0.0.1:8642/health
curl http://127.0.0.1:9119/api/status

Lệnh đầu phải trả trạng thái ổn. Nếu chưa lên, kiểm tra gateway đã chạy và API_SERVER_ENABLED đã bật.

Dùng mô hình cục bộ

README có hướng dẫn trỏ HERMES_API_URL vào Ollama (OLLAMA_ORIGINS=* ollama serve, rồi HERMES_API_URL=http://127.0.0.1:11434 pnpm dev). Ở chế độ không có gateway này (portable), phiên, bộ nhớ và kỹ năng hiện "Not Available". Muốn đủ chức năng thì phải qua gateway Hermes.

Cảnh báo bảo mật từ README

  • Mở 0.0.0.0 mà không có HERMES_PASSWORD thì Workspace từ chối chạy.
  • COOKIE_SECURE=0 gửi cookie phiên qua HTTP thường, chỉ dùng trong LAN tin cậy.
  • GATEWAY_ALLOW_ALL_USERS=true bỏ danh sách người được phép trên gateway.
  • TRUST_PROXY=1 chỉ khi đứng sau proxy đã làm sạch tiêu đề chuyển tiếp.
  • HERMES_ALLOW_INSECURE_REMOTE=1 tắt chốt chặn khi mở ra ngoài, README không khuyến nghị.

Giao diện có terminal và trình soạn tệp, nghĩa là ai vào được là điều khiển được máy bạn. Truy cập từ xa nên qua Tailscale hoặc VPN.

Bước tiếp theo
