ChatGPT Image for marketing content: posters, mockups and idea maps

How to use ChatGPT image generation for posters, mockups and idea diagrams: writing prompts, editing in parts, checking text in images, copyright notes.

By Hữu Hùng · Published: 2026-04-24 · 7 min read

Quick answer: ChatGPT can create and edit images right in the conversation. For marketing, write prompts with a clear purpose, refine part by part instead of starting over, and check the text in the image carefully, especially Vietnamese diacritics, before you use it.

What this feature can do

According to OpenAI's help page, you can create an image by describing it in a conversation, or by opening Images in the sidebar and entering a prompt. You can create images in several aspect ratios, start from an existing template, answer ChatGPT's suggested style questions, and on mobile sketch a drawing and add instructions. Images are saved automatically in Images. This feature replaces the old DALL·E tool, which has been discontinued. Plan details and limits change over time, so see the current help page.

Three kinds of marketing output that are common

Posters and ad visuals. State the purpose, audience, main message, style, layout and an aspect ratio that suits the channel you post to.

Mockups. Place a product in context: a cup, a bag, a phone screen, packaging. A mockup is good for presenting ideas, but it does not replace a real product photo when selling.

Idea maps (diagrams). Used for thinking and presenting: grouping ideas and the links between topics. Treat these as visual drafts, because text and connections in an AI-drawn diagram can be wrong.

How to write a good prompt

An effective prompt has all of these parts:

Purpose: promotional poster for a coffee shop, posted on Facebook, square ratio.
Main text: "Buy 1 get 1 free on Friday".
Style: minimalist, cream background, coffee-brown color, one cup of coffee in the center.
Layout: text in the top half, the cup in the bottom half, plenty of empty space.
Avoid: lots of small text, garish effects.

The more specific you are about purpose, layout and text, the less you need to fix.

Edit instead of redoing

OpenAI's help says you can select a region in the image and describe the change, or describe the edit in the conversation. It also warns that the selection is not always precise and edits can spill outside the selected area. So state clearly which area to change in the prompt, and change only one thing at a time so you know which change produced which result.

Checking text in images

The documentation says you can ask for text to be added to an image, but it does not state how reliable that is. For Vietnamese, check each image yourself:

  • Is the spelling correct and are all the diacritics present.
  • Is the font easy to read and does it suit the brand.
  • Do any strange words or stray characters appear.

If the text is an important part, the sure way is to create a background image and then add the text with a design tool.

Keeping the brand consistent

  • Write the color, style and ratio rules into one description you reuse for every image.
  • Save the prompts that give good results to use as templates.
  • View the images side by side to make sure they share one visual world.

Legal and reputation notes

  • Terms of use: read OpenAI's terms on the right to use generated images for commercial purposes. This article does not claim any specific ownership or limits.
  • Images of real people and brands: do not use it to impersonate real people or other people's brands.
  • Transparency: if an image could lead customers to think it is a real photo of the product, say clearly that it is an illustration.
  • Check before posting: AI-generated images can contain wrong details such as hands, text and odd logos.
