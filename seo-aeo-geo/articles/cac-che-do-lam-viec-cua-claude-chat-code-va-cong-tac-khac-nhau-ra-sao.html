Các chế độ làm việc của Claude: chat, code và cộng tác khác nhau ra sao?

Phân biệt các chế độ làm việc của Claude gồm chat, Claude Code và cộng tác trên file: mỗi chế độ làm được gì, hợp việc nào và khác nhau thế nào về quyền truy cập.

Tác giả: Hữu Hùng · Xuất bản: 2026-05-06 · 6 phút đọc

Trả lời nhanh: Dùng chat để hỏi đáp, viết và phân tích trong khung hội thoại. Dùng Claude Code khi cần làm việc trực tiếp trên thư mục code của bạn. Dùng chế độ cộng tác khi muốn Claude làm việc với file và ứng dụng trên máy cho các công việc không phải lập trình. Càng gần file của bạn, càng cần chú ý quyền truy cập.

Vì sao nên phân biệt

Cùng một mô hình nhưng ba chế độ làm việc rất khác nhau về việc nó có thể làm gì với máy và dữ liệu của bạn. Chọn nhầm chế độ vừa làm chậm công việc, vừa có thể gây rủi ro không cần thiết. Bài này giúp bạn chọn đúng chế độ cho từng loại việc.

Chế độ 1: Chat

Đây là khung hội thoại quen thuộc. Bạn nhập câu hỏi hoặc dán nội dung, Claude trả lời bằng văn bản. Tùy phiên bản, bạn có thể đính kèm tài liệu, hình ảnh, tạo nội dung như bản nháp hay mã nguồn ngay trong cuộc trò chuyện, và tổ chức công việc dài theo dự án.

  • Hợp với: hỏi đáp, soạn thảo, tóm tắt tài liệu, phân tích ý tưởng, học một chủ đề mới.
  • Quyền: thường chỉ làm việc với những gì bạn đưa vào cuộc trò chuyện. Nó không tự đọc hay sửa file trên máy bạn.
  • Rủi ro: thấp, chủ yếu là dữ liệu nhạy cảm bạn tự dán vào.

Chế độ 2: Claude Code

Claude Code là trợ lý lập trình làm việc trực tiếp trên thư mục dự án của bạn, thường qua terminal. Nó đọc code, sửa file, chạy lệnh và kiểm tra kết quả, với các hành động quan trọng cần bạn cho phép.

  • Hợp với: viết và sửa code, xây website nhỏ, tự động hóa bằng script, làm việc trên nhiều file cùng lúc, và cả những thư mục văn bản như vault ghi chú.
  • Quyền: đọc và ghi trong thư mục bạn mở, chạy lệnh theo quyền bạn cấp.
  • Rủi ro: trung bình đến cao nếu cấp quyền rộng. Hãy dùng Git và chế độ chỉ lập kế hoạch khi mới bắt đầu.

Xem hướng dẫn từng bước tại Thiết lập Claude Code từng bước.

Chế độ 3: Cộng tác trên file và ứng dụng

Đây là chế độ dành cho công việc không phải lập trình, nơi Claude làm việc với file và ứng dụng trên máy của bạn để hoàn thành một nhiệm vụ nhiều bước, như sắp xếp tài liệu, tổng hợp dữ liệu hay soạn báo cáo từ nhiều nguồn.

  • Hợp với: công việc văn phòng và tri thức có nhiều file, cần tổng hợp hoặc xử lý hàng loạt.
  • Quyền: truy cập vào thư mục và ứng dụng bạn cho phép.
  • Rủi ro: tương tự Claude Code. Chỉ mở đúng thư mục cần làm và kiểm tra kết quả trước khi dùng.

Tên gọi và tính năng của chế độ này thay đổi theo từng phiên bản, hãy xem mô tả hiện hành trong ứng dụng Claude bạn đang dùng.

Bảng chọn nhanh

Việc bạn cần                                   Chế độ nên dùng
---------------------------------------------  ----------------
Hỏi một câu, nhờ viết nháp, tóm tắt văn bản    Chat
Sửa code, thêm tính năng, chạy kiểm thử        Claude Code
Dọn dẹp, tổ chức lại cả thư mục ghi chú        Claude Code
Tổng hợp nhiều file tài liệu thành báo cáo     Cộng tác
Học một chủ đề, hỏi đáp về tài liệu bạn dán    Chat

Nguyên tắc chọn

  • Bắt đầu từ chế độ ít quyền nhất đủ dùng. Việc nào làm được trong chat thì không cần cấp quyền vào máy.
  • Chuyển sang chế độ có quyền khi việc cần làm trên file thật, và khi đó hãy có bản sao lưu.
  • Một thư mục, một nhiệm vụ. Chỉ mở thư mục liên quan, không mở cả ổ đĩa.
  • Luôn kiểm tra kết quả trước khi dùng, đặc biệt với file quan trọng.

Dữ liệu và quyền riêng tư

Ở mọi chế độ, nội dung bạn đưa cho Claude hoặc để nó đọc sẽ được xử lý bởi dịch vụ. Hãy xem chính sách dữ liệu hiện hành của nhà cung cấp, và đừng đưa vào thông tin mật khẩu, khóa truy cập hay dữ liệu khách hàng nhạy cảm nếu không cần thiết.

Kết hợp các chế độ

Cách làm hiệu quả thường là kết hợp: dùng chat để suy nghĩ và lập kế hoạch, dùng Claude Code hoặc chế độ cộng tác để thực hiện trên file, rồi quay lại chat để xem xét và chỉnh. Để biết cách đánh giá một agent làm việc trên file có đáng tin hay không, xem bài Đánh giá AI Agent qua bài test thực tế.
