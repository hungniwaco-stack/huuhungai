Cài OpenClaw Desktop App: cách bắt đầu với AI Agent giao diện sạch

Cài OpenClaw trên Windows, macOS hoặc Linux: ứng dụng Desktop, lệnh cài một dòng, bước onboarding, mở Control UI và kiểm tra Gateway đã chạy ổn.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-30 · 7 phút đọc

Trả lời nhanh: Theo tài liệu chính thức, bạn có thể cài OpenClaw bằng ứng dụng Desktop (Windows Hub, ứng dụng thanh menu macOS) hoặc một lệnh cài. Sau đó chạy onboarding, mở Control UI bằng openclaw dashboard và gửi tin nhắn đầu tiên. Gateway mặc định nghe ở cổng 18789, và cần Node 24.16 trở lên hoặc Node 26.

OpenClaw là gì

OpenClaw là cổng kết nối mã nguồn mở, tự lưu trữ (self-hosted), nối ứng dụng chat với agent AI. Bạn chạy một tiến trình Gateway trên máy của mình, nó là nguồn sự thật cho phiên, định tuyến và kết nối kênh. Dự án do OpenClaw Foundation duy trì, giấy phép MIT. Bài này nói về cách cài và chạy lần đầu theo tài liệu chính thức, không phải về các giao diện cộng đồng như ClawX hay Aion UI.

Yêu cầu

  • Node: 24.16.0 trở lên ở nhánh 24.x, hoặc 26.1.0 trở lên. Tài liệu khuyến nghị mạnh dùng 24.22.1 trở lên hoặc 26.12.1 trở lên vì lý do bảo mật, và khuyến nghị Node 26.
  • Hệ điều hành: macOS, Linux hoặc Windows. Trên Windows có thể dùng ứng dụng Windows Hub gốc, trình cài PowerShell hoặc Gateway chạy trong WSL2.
  • Khóa mô hình: một khóa API của nhà cung cấp, hoặc đăng nhập Claude Code hay Codex CLI sẵn có (onboarding có thể dùng lại).
  • pnpm chỉ cần khi bạn dựng từ mã nguồn.

Cách 1: ứng dụng Desktop

  • Windows Hub (khuyến nghị trên Windows): có bộ cài x64 và arm64 ở trang phát hành GitHub của OpenClaw, gồm phần thiết lập, trạng thái ở khay hệ thống, chat và chế độ node. Còn một ứng dụng Tauri dự phòng cho Windows, tệp OpenClaw-<phiên bản>-windows-x86_64.exe trong các bản phát hành thường.
  • macOS: tải OpenClaw-<phiên bản>.dmg (ưu tiên) hoặc .zip từ trang phát hành, cài và mở OpenClaw.app (ứng dụng thanh menu).

Hãy tải từ trang phát hành chính thức trên GitHub của dự án, tránh các bản sao.

Cách 2: trình cài một dòng (khuyến nghị trong tài liệu)

macOS, Linux và WSL2:

curl -fsSL https://openclaw.ai/install.sh | bash

Windows PowerShell:

iwr -useb https://openclaw.ai/install.ps1 | iex

Muốn cài mà không chạy onboarding ngay, thêm -- --no-onboard (bash) hoặc -NoOnboard (PowerShell). Các cách khác gồm npm install -g openclaw@latest, pnpm, bun, Docker, Podman, Nix hoặc dựng từ mã nguồn; mỗi cách có trang riêng trong tài liệu. Muốn thử nhanh không cài, có lệnh npx openclaw@latest.

Onboarding

Trình cài tự chạy trình hướng dẫn. Có hai lựa chọn:

  • Quick start: tự phát hiện quyền dùng AI đang có, kiểm tra bằng một lượt hoàn thành thật, lưu cấu hình và mở bảng điều khiển web. Nếu không route nào dùng được, nó chuyển sang thiết lập nhà cung cấp thủ công.
  • Custom setup: đi qua tất cả tùy chọn.

Quick start hỏi "Keep OpenClaw running in the background?". Chọn có thì Gateway được cài thành dịch vụ nền; chọn không thì Gateway chạy trong terminal cho tới khi bạn nhấn Ctrl+C. Cấu hình được lưu trong cả hai trường hợp. Đổi cài đặt sau này bằng openclaw configure. Nếu cài bằng npm, lệnh onboarding là openclaw onboard --install-daemon.

Kiểm tra sau khi cài

openclaw --version
openclaw doctor
openclaw gateway status

gateway status phải cho thấy Gateway đang nghe ở cổng 18789. Nếu Gateway chưa chạy: openclaw gateway install rồi openclaw gateway start. Lệnh start đợi tới khi Gateway qua kiểm tra sức khỏe, và không khởi động lại một Gateway đang chạy.

Mở giao diện và nhắn thử

openclaw dashboard

Lệnh này mở Control UI trên trình duyệt bằng một liên kết ghép cặp dùng một lần, hết hạn sau mười phút. Nếu giao diện tải được, bạn gửi tin nhắn đầu tiên trong khung chat và xác nhận có phản hồi từ AI. Thêm --no-open nếu chỉ muốn in địa chỉ ra terminal.

Khi có sự cố

openclaw triage chạy các kiểm tra chỉ đọc và tạo một lời nhắc chẩn đoán đã lọc bỏ khóa, token và nhật ký thô. Chẳng có gì rời máy cho tới khi bạn chọn một agent để xử lý. openclaw doctor cho cùng các phát hiện để bạn tự đọc. Trang Troubleshooting xếp cách sửa theo triệu chứng.

Lưu ý an toàn khi mới cài

Gateway điều khiển một agent có thể làm việc thật trên máy bạn, nên hãy giữ nó nghe ở loopback và dùng cơ chế ghép cặp mặc định cho người nhắn tin lạ. Tài liệu bảo mật còn có lệnh openclaw security audit để kiểm tra cấu hình. Khi cần truy cập từ xa, xem Control UI và truy cập từ xa. Cập nhật phiên bản bằng openclaw update và nên có bản sao lưu trước khi cập nhật lớn, như bài Lộ trình học OpenClaw mô tả.
