Claude Code AI SEO với Netlify và MCP: workflow xuất bản nội dung

Kết nối Claude Code với Netlify qua MCP để xuất bản website nội dung: cách thêm máy chủ MCP, quy trình an toàn và điều cần kiểm soát trước khi đăng.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-18 · 7 phút đọc

Trả lời nhanh: MCP cho phép Claude Code dùng công cụ bên ngoài, trong đó có máy chủ MCP của Netlify để làm việc với site của bạn. Quy trình an toàn là để AI soạn và sửa nội dung trong kho code, xem trước ở bản preview, rồi bạn tự duyệt trước khi đưa lên site chính.

MCP và Netlify MCP là gì

MCP (Model Context Protocol) là chuẩn để các công cụ AI kết nối với dịch vụ bên ngoài. Netlify cung cấp một máy chủ MCP kết nối agent với Netlify và công cụ dòng lệnh của họ. Bạn có thể dùng nó để agent thao tác với site Netlify của mình thay vì phải tự gõ từng lệnh. Danh sách công cụ cụ thể máy chủ cung cấp được Netlify ghi trong tài liệu riêng, hãy xem đó thay vì suy đoán.

Cách thêm máy chủ MCP của Netlify

Theo tài liệu của Netlify, cách được khuyến nghị là máy chủ từ xa:

npx -y add-mcp https://mcp.netlify.com/mcp

Lệnh này chạy tương tác để bạn chọn các agent cần cấu hình (có Claude Code). Với môi trường bắt buộc chạy máy chủ cục bộ, tài liệu đưa ra cách khác:

npx -y add-mcp "npx -y @netlify/mcp"

Tài liệu cũng cho biết kết nối cũ tại địa chỉ netlify-mcp.netlify.app vẫn hoạt động, nhưng kết nối mới nên dùng mcp.netlify.com. Netlify có một hướng dẫn riêng cho Claude Code, hãy xem trang đó để biết các bước chi tiết và yêu cầu phiên bản Node.js hiện hành.

Quy trình xuất bản nội dung đề xuất

  1. Nội dung nằm trong kho code (Markdown hoặc trang HTML), có Git để theo dõi thay đổi.
  2. Claude Code soạn hoặc sửa bài theo brief và quy tắc trong CLAUDE.md, xem Claude Code SEO Agent.
  3. Kiểm tra on-page tự động: tiêu đề, mô tả meta, đề mục, canonical, liên kết hỏng.
  4. Xem trước: đẩy lên nhánh riêng và để Netlify dựng một bản xem trước (deploy preview).
  5. Bạn duyệt nội dung và dữ kiện trên bản xem trước.
  6. Gộp vào nhánh chính để xuất bản, theo quy trình bạn đã quy định.

Những điều cần kiểm soát

  • Quyền của agent. Chỉ cấp những gì cần. Với tác vụ có thể làm hỏng site hoặc ảnh hưởng chi phí, hãy yêu cầu xác nhận trước khi thực hiện.
  • Không tự xuất bản. Việc đưa lên site chính nên do bạn quyết định, không để agent tự làm.
  • Bí mật. Khóa truy cập, biến môi trường không nên nằm trong kho code hay trong đầu vào của agent.
  • Xác thực. Máy chủ MCP kết nối bằng tài khoản của bạn, nên hành động của agent có hiệu lực thật. Hãy kiểm tra các quyền được cấp trong tài khoản.
