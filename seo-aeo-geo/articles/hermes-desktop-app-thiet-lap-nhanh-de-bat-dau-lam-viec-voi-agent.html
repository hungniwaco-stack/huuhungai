AGENT / AI Agent

Hermes Desktop App: thiết lập nhanh để bắt đầu làm việc với agent

Hermes Desktop: cài trên Windows, macOS hoặc Linux, kết nối cục bộ hoặc từ xa, các tính năng chính, cập nhật, gỡ cài đặt và những cảnh báo bảo mật cần biết.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-28 · 7 phút đọc

Trả lời nhanh: Hermes Desktop là ứng dụng máy tính của Hermes Agent, dùng chung cấu hình, khóa, phiên, kỹ năng và bộ nhớ với bản dòng lệnh. Cài bằng gói tải về, chọn nhà cung cấp mô hình ở lần chạy đầu rồi trò chuyện. Mặc định nó chạy gateway cục bộ trên máy bạn.

Desktop là gì

Theo tài liệu, Hermes Desktop là ứng dụng gốc cho macOS, Windows và Linux, xây quanh đúng agent của bản CLI và gateway. Điều này có nghĩa cái bạn thiết lập trong terminal sẽ hiện ra trong ứng dụng và ngược lại. Nó không phải một agent thứ hai.

Cài đặt

  • macOS (chip Apple Silicon): mở tệp DMG, kéo Hermes.app vào Applications.
  • Windows: mở tệp .appinstaller bằng Windows App Installer.
  • Đã cài Hermes bằng dòng lệnh: chạy hermes desktop; ứng dụng dùng luôn cấu hình, khóa, phiên và kỹ năng hiện có.

Gói Desktop không đòi điều kiện biên dịch. Tải từ trang chủ chính thức của Hermes Agent. Nếu chưa có gì, xem Cài Hermes Agent đơn giản.

Lần chạy đầu

Ứng dụng có thể cài phần lõi của agent vào thư mục HERMES_HOME. Màn hình giới thiệu đưa bạn tới tin nhắn đầu tiên nhanh nhất có thể, bạn được chọn "Choose provider later" nếu chưa muốn cấu hình nhà cung cấp. Lựa chọn giao diện: Basic bắt đầu ở chế độ Simple, Elite bắt đầu ở chế độ Advanced.

Ba kiểu kết nối

Ở Settings, mục Gateways:

  • Local (mặc định): ứng dụng chạy hermes gateway ensure cho profile đang dùng. Gateway vẫn chạy sau khi bạn thoát ứng dụng.
  • Remote gateway: nhập địa chỉ của một backend hermes serve do bạn tự chạy (ví dụ dạng http://<máy>:9119) rồi đăng nhập. Ứng dụng không tự khởi động backend đó.
  • Hermes Cloud: đăng nhập và chọn một agent trong tài khoản, không cần địa chỉ.

Về đăng nhập: tên người dùng và mật khẩu chỉ nên dùng trong mạng tin cậy; OAuth qua Nous Portal được khuyến nghị cho mọi thứ hướng ra Internet.

Tính năng chính

  • Trò chuyện: phản hồi dạng dòng chảy, hiển thị hoạt động công cụ, kéo thả tệp đính kèm, khung xem trước bên phải, tìm trong trang (Ctrl hoặc Cmd + F), hàng đợi tin nhắn.
  • Thanh trạng thái: công tắc YOLO theo từng phiên, đồng hồ mức dùng ngữ cảnh, tùy chọn hiển thị lượt trúng bộ đệm và token mỗi giây.
  • Chọn mô hình: nằm ngay ô soạn tin. Mô hình mặc định đặt ở Settings, Model, Main model rồi bấm Apply. Tác tử con có mục riêng ở Settings, Model, Subagents.
  • Công cụ lập trình: trình duyệt tệp, terminal (Ctrl + `), khung xem Git (Ctrl hoặc Cmd + G), worktree (Ctrl hoặc Cmd + Shift + B).
  • Khác: Artifacts, đồ thị bộ nhớ, Quick Entry bằng phím tắt toàn cục (mặc định Ctrl hoặc Cmd + Shift + Space), giọng nói, chế độ HUD (thanh nổi luôn ở trên).
  • Bot Mode: mỗi profile hiện thành một bot có chat và tác vụ định kỳ riêng.
  • Các khung quản lý: kỹ năng, cron, profile, nhắn tin, nhà cung cấp.
  • Webapp: bật bằng hermes config set webapp.enabled true, khởi động lại gateway bằng hermes gateway restart, rồi chạy hermes webapp để mở không gian làm việc trên trình duyệt.

Cập nhật và gỡ cài đặt

Ứng dụng kiểm tra bản mới ở nền và cho cập nhật một cú bấm. Truy vấn GitHub ẩn danh bị giới hạn theo địa chỉ mạng; ứng dụng có thể dùng GITHUB_TOKEN, GH_TOKEN hoặc phiên đăng nhập GitHub CLI để nới giới hạn. Với gateway từ xa, "Update now" cập nhật backend trước, rồi đến ứng dụng.

Gỡ cài đặt ở Settings, About, Danger zone, có ba mức: chỉ gỡ giao diện, gỡ giao diện và agent nhưng giữ dữ liệu, hoặc gỡ tất cả.

Cảnh báo cần biết

  • Webapp có quyền cấp máy chủ: người đăng nhập có thể chạy lệnh dưới tài khoản đang chạy Hermes. Đừng mở ra ngoài khi chưa có nhà cung cấp đăng nhập.
  • HTTP thường làm mất tính năng cần ngữ cảnh an toàn như micro, đọc clipboard và thông báo (địa chỉ loopback được miễn).
  • Plugin Desktop không chạy trong hộp cát, chúng có đầy đủ quyền của ứng dụng. Chỉ cài plugin bạn tin.
  • Đổi mô hình giữa chừng làm mất bộ nhớ đệm, lượt kế tiếp có thể đắt hơn.
  • Backend từ xa phải do bạn giữ chạy, và trên Linux việc thu nhỏ xuống khay hệ thống cần thành phần khay phù hợp.

Dùng Desktop như thế nào cho hợp lý
