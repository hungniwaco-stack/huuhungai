OpenClaw và Kimi: cấu hình Moonshot, Kimi Coding và Ollama Cloud

Dùng Kimi với OpenClaw qua Moonshot AI và Kimi Coding: biến khóa, cấu hình mẫu, endpoint Trung Quốc, Ollama Cloud và lưu ý về chi phí, dữ liệu.

Tác giả: Hữu Hùng · Xuất bản: 2026-04-22 · 7 phút đọc

Trả lời nhanh: OpenClaw hỗ trợ Kimi qua hai đường: Moonshot AI (MOONSHOT_API_KEY, mô hình moonshot/kimi-k2.6) và Kimi Coding (KIMI_API_KEY, mô hình kimi/kimi-for-coding). Cả hai có lệnh onboarding sẵn. Ngoài ra có thể gọi Kimi qua Ollama Cloud. Số giá trong cấu hình mẫu của tài liệu chỉ là giá trị ví dụ, đừng dùng để tính ngân sách.

"Mô hình mở" và điều cần nói rõ

Bài này nói về cách nối Kimi vào OpenClaw. Nhiều bài viết gọi chung các mô hình như Kimi là "mô hình mở", nhưng việc một mô hình có được công bố trọng số hay không là chuyện riêng của từng bản. Khi bạn dùng API Moonshot, bạn dùng dịch vụ đám mây của họ, không phải chạy trọng số trên máy mình. Cách chạy mô hình trên máy xem DeepSeek và OpenClaw: local gateway.

Đường 1: Moonshot AI (Kimi qua API Moonshot)

Cấu hình mẫu trong tài liệu "Provider examples" (JSON5):

{
  env: { vars: { MOONSHOT_API_KEY: "sk-..." } },
  agents: {
    defaults: {
      model: { primary: "moonshot/kimi-k2.6" },
      models: { "moonshot/kimi-k2.6": { alias: "Kimi K2.6" } },
    },
  },
  models: {
    mode: "merge",
    providers: {
      moonshot: {
        baseUrl: "https://api.moonshot.ai/v1",
        apiKey: "${MOONSHOT_API_KEY}",
        api: "openai-completions",
        models: [
          { id: "kimi-k2.6", name: "Kimi K2.6", reasoning: false, input: ["text", "image"],
            cost: { input: 0.95, output: 4, cacheRead: 0.16, cacheWrite: 0 },
            contextWindow: 262144, maxTokens: 262144 },
        ],
      },
    },
  },
}
  • Biến khóa MOONSHOT_API_KEY, mô hình tham chiếu moonshot/kimi-k2.6.
  • Endpoint Trung Quốc: đổi baseUrl thành https://api.moonshot.cn/v1, hoặc chạy openclaw onboard --auth-choice moonshot-api-key-cn.
  • Các số cost và contextWindow trong khối trên là phần của ví dụ cấu hình. Hãy đối chiếu giá và giới hạn thật trên trang của Moonshot trước khi dựa vào.

Đường 2: Kimi Coding

{
  env: { vars: { KIMI_API_KEY: "sk-..." } },
  agents: {
    defaults: {
      model: { primary: "kimi/kimi-for-coding" },
      models: { "kimi/kimi-for-coding": { alias: "Kimi Code" } },
    },
  },
}

Đây là nhà cung cấp tích hợp sẵn, tương thích Anthropic. Lối tắt onboarding: openclaw onboard --auth-choice kimi-code-api-key.

Đường 3: Kimi qua Ollama Cloud

Trong bảng plugin nhà cung cấp, Ollama Cloud (mã ollama-cloud, biến OLLAMA_API_KEY) có ví dụ mô hình ollama-cloud/kimi-k2.6. Chi tiết xem DeepSeek, OpenClaw và Ollama Cloud, gồm các lưu ý về dữ liệu của Ollama.

Chọn đường nào

  • Cần tích hợp thẳng với Moonshot và quản lý chi phí theo tài khoản Moonshot: đường 1.
  • Chủ yếu để lập trình và muốn nhà cung cấp dựng sẵn: đường 2.
  • Đã dùng Ollama và muốn một tài khoản: đường 3.

Hãy thử cùng một việc thật trên các mô hình bạn đang cân nhắc và so sánh độ đúng, tốc độ và chi phí, thay vì tin bảng so sánh chung. Khung chấm điểm xem Đánh giá AI Agent qua bài test thực tế.

Dự phòng và quyền công cụ

Đặt dự phòng bằng agents.defaults.model.fallbacks; nếu bạn chọn mô hình thủ công bằng /model, lỗi sẽ được báo thay vì chuyển dự phòng. Mô hình bên ngoài có thể kém bền trước chèn lệnh hơn mô hình đầu bảng, nên giữ quyền công cụ hẹp và đọc bài học bảo mật.

Lưu ý về dữ liệu

Dùng API nghĩa là nội dung hội thoại, kể cả tệp agent đọc, gửi tới nhà cung cấp. Hãy đọc chính sách dữ liệu của Moonshot (và của Ollama nếu dùng đường 3) và chọn đúng endpoint theo vùng của bạn. Đừng đưa dữ liệu khách hàng hay bí mật vào khi chưa chắc.
