AGENT / AI Agent

Thiết lập Aion UI với OpenClaw: giao diện điều khiển agent

Aion UI là ứng dụng Desktop mã nguồn mở chạy chung OpenClaw, Claude Code, Codex và nhiều agent khác: cách cài, nhận diện agent, đồng bộ MCP, WebUI và lưu ý.

Tác giả: Hữu Hùng · Xuất bản: 2026-05-02 · 7 phút đọc

Trả lời nhanh: Aion UI (kho iOfficeAI/AionUi, giấy phép Apache-2.0) là ứng dụng Desktop gom nhiều agent vào một giao diện: có agent tích hợp sẵn và tự nhận diện các CLI đã cài như OpenClaw, Claude Code, Codex. Cài bằng bản phát hành hoặc brew install aionui trên macOS. Dữ liệu lưu cục bộ trong SQLite.

Aion UI là gì

README của dự án mô tả đây là ứng dụng "Cowork" miễn phí, mã nguồn mở: agent làm việc trên máy bạn (đọc tệp, viết mã, duyệt web, tự động hóa việc) và bạn duyệt các hành động. Ứng dụng có agent tích hợp riêng, đồng thời chạy được các agent CLI bên ngoài trong cùng một giao diện. Đây là dự án cộng đồng, không phải sản phẩm của OpenClaw Foundation. Bản chính thức của OpenClaw xem ở Cài OpenClaw.

Yêu cầu

  • macOS 10.15 trở lên, Windows 10 trở lên, hoặc Linux (Ubuntu 18.04 trở lên, Debian 10 trở lên, Fedora 32 trở lên).
  • Khuyến nghị từ 4 GB RAM, trống ít nhất 500 MB ổ đĩa.

Cài đặt

  • Tải bộ cài cho hệ điều hành ở trang Releases của kho iOfficeAI/AionUi.
  • macOS có thể dùng Homebrew:
brew install aionui

README không liệt kê trình quản lý gói nào khác. Tìm kiếm cho thấy nhiều bản fork cùng mô tả; hãy dùng kho iOfficeAI gốc.

Nhận diện agent và OpenClaw

Aion UI tự dò các công cụ CLI đã cài trên máy. README nói nếu bạn dùng Claude Code, Codex, Hermes Agent hoặc OpenClaw thì ứng dụng nhận ra và cho làm việc song song với agent tích hợp; còn liệt kê Gemini CLI, OpenCode, Cursor Agent và khoảng 20 agent khác. Một hướng dẫn cộng đồng cũng nói ứng dụng có trợ lý thiết lập cho OpenClaw. Số agent hỗ trợ giữa các nguồn không khớp nhau, hãy xem danh sách ở kho chính. Muốn dùng OpenClaw qua Aion UI, bạn cài và chạy được OpenClaw trước.

Tính năng chính theo README

  • Chế độ nhiều agent: các phiên song song, mỗi phiên có ngữ cảnh riêng. Chế độ nhóm: agent Leader chia việc cho các agent Teammate dùng chung không gian làm việc.
  • Quản lý MCP một nơi: cấu hình công cụ MCP và Aion UI tiêm hoặc đồng bộ vào từng agent theo khả năng của nó.
  • Mô hình: hỗ trợ hơn 30 nhà cung cấp, gồm Gemini, Anthropic, OpenAI và chạy cục bộ như Ollama, LM Studio.
  • Tác vụ định kỳ: theo giờ, theo chu kỳ hoặc một lần, chạy không cần người trực.
  • Khung xem trước hơn 10 định dạng (PDF, Office, mã, ảnh).
  • Truy cập từ xa bằng WebUI: chạy như một máy chủ HTTP riêng, đăng nhập bằng mã QR hoặc mật khẩu, dùng trong mạng LAN, qua mạng ngoài hoặc trên máy chủ.
  • Kênh chat: Telegram, Lark (Feishu), DingTalk, WeChat; WeCom, Slack, Discord ghi là sắp có.

Dữ liệu và bảo mật

README nói mọi dữ liệu lưu cục bộ trong cơ sở dữ liệu SQLite và không tải lên máy chủ nào. Điều này chỉ nói về ứng dụng; mô hình bạn chọn vẫn nhận nội dung bạn gửi. Với WebUI từ xa, hãy dùng mật khẩu mạnh, ưu tiên mạng riêng hoặc VPN, vì giao diện này điều khiển agent có thể chạy lệnh trên máy bạn.

Nên dùng khi nào

Hợp nếu bạn dùng nhiều agent và muốn một giao diện chung. Nếu chỉ dùng OpenClaw, giao diện chính thức (Control UI) hoặc ClawX có thể đủ. Cũng cần cân nhắc: thêm một lớp phần mềm là thêm một thứ để cập nhật và tin cậy, nên đừng cài cả ba giao diện cùng lúc.
